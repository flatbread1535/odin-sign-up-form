Odin Sign-Up Form

This project uses HTML and CSS to create a sign-up form webpage. This project was created for the Odin Project with the intention of practicing intermediate HTML and CSS concepts such as forms, CSS units & properties, and advanced selectors.

This project contains:
- Relative CSS Units (rem/vw/vh)
- Importing Custom Text Style
- Important CSS Properties (box-shadow, overflow, opacity)
- Absolute/Relative Positioning
- Child Combinators, Pseudo-Class Selectors, & Attribute Selectors
- Form Basics & Form Validation
